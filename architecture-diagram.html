Core Workflows
1
Auth & Verification: User registers → SMTP verification email → Token validated → JWT session.
2
Custom Pizza Builder: Client configures 4 stages → Real-time price compute → Checkout summary.
3
Razorpay Payment: Server creates order → Modal checkout → HMAC SHA256 verified → Order placed.
4
Auto Stock Decrement: Pizza ingredients atomically decremented in MongoDB upon payment verification.
5
Admin & Cron Alerts: Admin manages orders & inventory → Hourly Cron triggers email if stock < threshold.
