# OIBSIP — Oasis Infobyte Internship

This repository contains all task submissions for the Oasis Infobyte Internship Program (OIBSIP).

## Repository Structure

Each task lives in its own folder, named in the strict format:

```
OIBSIP/[TrackName]-[Level/Task]-[ProjectName]/
```

Examples:

- `OIBSIP/WebDev-L1-LandingPage/`
- `OIBSIP/Python-Task2-BMICalculator/`
- `OIBSIP/DataAnalytics-L1-EDARetailSales/`
- `OIBSIP/CyberSecurity-Task4-NetworkThreatsReport/`

Every task folder contains:

- Source code for the project
- A `README.md` describing the project
- Screenshots / output files where relevant
